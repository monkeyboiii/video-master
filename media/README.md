# media/ — heavy files, outside git

Everything under `media/` except this README and `.gitkeep` files is **git-ignored**.
The manifest (`series/S0N/E0NN-slug/manifest.yml`) records every file's name, purpose, and
external location — **if a file isn't in a manifest, it doesn't exist.**

That sentence is load-bearing, and it is why the S0N migration renamed nothing here. Because the
manifest records each asset's `filename:` explicitly, the id and the filename were never actually
coupled — the old naming patterns only made them look coupled by starting every example with
`{VIDEO_ID}_`. Files carrying the retired `DBX-APP-S03E003_…` prefix are still correct and are not
to be renamed; new files may be short, since they are already addressed by their episode.

| Directory | Contents | Named per |
|-----------|----------|-----------|
| `raw/` | Camera originals, organized `raw/<video_id>/` — e.g. `raw/S03E003/` | shot pattern |
| `selected/` | Trimmed selects (optional — selects normally live as in/out timecodes in the manifest, not files) | n/a |
| `proxies/` | Edit proxies (usually generated by Kdenlive itself) | Kdenlive-managed |
| `overlays/` | Remotion renders, ProRes 4444 `.mov` | overlay pattern |
| `voiceover/` | VO recordings per locale | VO pattern |
| `audio/` | Music and SFX used by episodes | free, but referenced in manifests |
| `timelines/` | Working `.kdenlive` projects | timeline pattern |
| `exports/` | Review/final renders + cover stills | export/cover patterns |

Patterns: [`agents.d/modules/naming-conventions.md`](../agents.d/modules/naming-conventions.md) § Media filenames are RECORDED, not DERIVED. Music/SFX in `audio/` must be recorded in the
manifest's `assets.audio` with `source` and `license` — only tracks licensed for
commercial social-media use.

## Per-project handoff bundle

The type-first layout above is the default. For a video that's ready to hand to an editor
on another machine, an alternative is a **self-contained bundle** `media/<VIDEO_ID>/` with
everything for that one cut in one folder (`footage/`, `overlays/`, `voiceover/`, `music/`,
subtitles, plus `_source/` backups) and its own `README.txt`. Copy that single folder to
the editing machine. Example: `media/DBX-APP-S01E003/` (see the
episode's `edit-notes.md`).

## External storage

Every raw/VO/export file gets an `external_uri` in the manifest so it can be found after
this machine's `media/` is cleaned. Canonical layout (mirror of `media/`):

```text
<STORE>/raw/<VIDEO_ID>/...
<STORE>/voiceover/<VIDEO_ID>/...
<STORE>/exports/<VIDEO_ID>/...
```

> **DECIDE (human):** `<STORE>` is not chosen yet. Pick the real location (e.g.
> `s3://dirtbikex-video` or a synced drive path), replace this note, and use it in every
> `external_uri` from then on. Until then the validator only warns about missing
> `external_uri` values.
