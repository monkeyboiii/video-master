# S06 — The machine, explained

One mechanical question per episode, answered with drawn diagrams instead of footage. No track
visit, no counter, no interview — the whole episode is a sequence of panels and a voice explaining
what is happening inside the engine. That is the entry test: if the answer needs a diagram to be
believed, it belongs here; if it needs a place or a person, it belongs in S03 or S05.

**These are the only episodes in the estate authored in both editions from the start.** A mechanism
is the same in every language, so the two variants say the same things in the same order — and per
`agents.d/modules/localization.md` that is still not a translation: each edition is written
idiomatically, and the review bar it must pass is "does it read like it was written in this
language", not "does it match the other one".

## The colour convention is load-bearing

Green is forward rotation, blue is cylinder pressure, red is reverse torque. It holds across every
panel of every episode in this season, and the direction is locked with it: **green turns clockwise,
red turns counter-clockwise.** A viewer who has watched one episode has learned the notation, and
an episode that breaks it teaches them wrong. E001's source art shipped in two versions and the
first one had green and red turning the same way — a reversal that goes the direction it is
reversing from — which is exactly the error this rule exists to catch.

## Where it stands

- E001 is `topic`. The panels exist as source art; nothing is shot, and there is no take in either
  language — the voice in the previz is synthesised.
- No episode here has a cover, and covers are the gate to `packaging`.
