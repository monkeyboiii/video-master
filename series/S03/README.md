# S03 — The 100-track challenge

A counted field mission: ride to a real dirt bike track, meet whoever keeps it running, and put it
on the map. One track per episode, counted toward 100. The app arrives as a consequence of the
visit rather than as a pitch, and the register is self-deprecating where S01's founder story was
sincere.

**The count is visits, not signups.** E002's boss turned the app down and the counter ticked
anyway — the script says so outright. **E000 does not count**: it visits no track, opens the
counter at 0, and exists to state the premise. The first tick is E001.
